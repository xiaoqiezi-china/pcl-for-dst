# 脱敏标准

发布开源版（或把仓库公开）之前，按本文逐项过一遍。本文只针对"泄露或误导"，不涉及功能。

## 一、硬性红线：必须零残留

这一类一旦泄露就是**可用凭据外流**，必须删除并**轮换**（删掉不等于没泄露过，历史记录、备份、聊天记录里都可能有）。

| 项目 | 现存位置 | 处理 |
| --- | --- | --- |
| 微软登录 ClientId | `Modules/ModSecret.Local.vb` | 移出仓库；该文件已在 `.gitignore` |
| CurseForge API Key | 同上 | 移出仓库，并到 CurseForge 后台**重新签发** |
| 机器人服务令牌 | 同上 | 移出仓库，并到服务端**重置** |
| 机器人预设服务地址 | 同上 | 移出仓库 |
| 自定义服务地址 / 令牌 | 用户设置 `DstBotApiUrl`、`DstBotToken` | 不得写进代码或文档截图 |

> 判定标准：任何形如 `ak_` 开头的长串、`$2a$10$` 开头的哈希、带端口的 http 地址，都不允许出现在提交里。

## 二、个人信息

| 项目 | 来源 | 处理 |
| --- | --- | --- |
| QQ 号、昵称、群号、群名 | 截图、日志、公告文案 | 打码；不要把真实群号写进仓库 |
| 玩家名、存档名、世界路径 | 截图（存档管理 / 地图 / 玩家数据） | 换成示例名，或裁掉路径行 |
| 本机用户名、盘符路径 | 日志、截图、配置示例 | 统一替换为占位路径 |
| 服务器 IP / 端口 | 主页服务器列表 | 打码后再放截图 |

## 三、定制化信息

开源版应当是"一个增强版 PCL"，**不带任何运营方信息**。逐项确认：

- [ ] `ModSecret.Local.vb` 不存在（或为空模板）
- [ ] `LauncherName` / `LauncherShortName` 不含运营方名称
- [ ] 免责声明、更新公告、关于页里不含运营方名称与联系方式
- [ ] 机器人预设服务为空，`DstBot.HasService` 在默认配置下为 `False`
- [ ] 主题名、页面文案里不含运营方品牌
- [ ] 注册表目录 `RegFolder` 与官方版隔离，但不带品牌词

## 四、构建产物与本地文件

以下内容**不得进仓库**（已在 `.gitignore` 中）：

- `bin/`、`obj/`、`*.pdb`、文档 XML
- 工具链临时文件（`.dsh-ops-update-*.lock` 等）
- 本地运行数据：`PCL/`、`.minecraft/`
- 打包产物：`dist/`、`build-check/`

## 五、发布前的自动检查

```bash
cd src

# 1. 确认本地凭据文件没有被跟踪
git ls-files | grep -i 'ModSecret.Local' || echo "OK：未跟踪"

# 2. 确认忽略规则生效
git check-ignore -v 'Plain Craft Launcher 2/Modules/ModSecret.Local.vb'

# 3. 凭据样式残留扫描（应无输出）
git grep -nE 'ak_[A-Za-z0-9]{16,}|\$2[aby]\$' -- . ':!LICENCE'

# 4. 运营方关键词（应只剩署名等合规用途）
git grep -niE '帝释天|sjcmc' -- .
```

## 六、开源版的默认行为

| 项目 | 开源版默认 | 说明 |
| --- | --- | --- |
| 登录方式 | 离线 | 没有 ClientId 时不引导做正版登录 |
| 微软 ClientId | 空 | 用户可在 设置 → 其他 → 账号与 API 填写 |
| CurseForge Key | 空 | 同上；为空时搜索只走其他来源并给出提示 |
| 远程服务（机器人） | 未配置 | 相关入口整体隐藏 |
| 内置凭据 | 无 | 若构建方要内置，仍走 `ModSecret.Local.vb` |

## 七、内置凭据（构建方自行决定）

想让开源版也带默认凭据，**不要写死在 `ModSecret.vb`**，而是新建 `Modules/ModSecret.Local.vb`（该文件已被忽略）：

```vb
Friend Module ModSecretLocal
    Public Const ClientId As String = "你的 Azure 应用 ID"
    Public Const CurseForgeKey As String = "你的 CurseForge Key"
    ' 不打算用远程服务就留空
    Public Const PresetApi As String = ""
    Public Const PresetToken As String = ""
End Module
```

文件存在时，工程会自动定义 `DST_LOCAL` 编译符号；不存在时按开源版处理（凭据为空）。

> 注意：一旦随二进制分发出去，内置凭据就等于公开，随时可能被滥用。更稳妥的做法是**只内置 ClientId**，CurseForge Key 让用户自备。
